## PART 4: SEO TECHNICAL CHECKLIST

### On-Page SEO for Every Blog Post
- [ ] Title includes primary keyword (within first 60 characters)
- [ ] H1 = title. H2s include secondary keywords naturally
- [ ] First paragraph answers the search query directly
- [ ] Internal links: minimum 3 links to other Fin-Eye content + 1 to the app
- [ ] External links: 2–3 authoritative sources (FRED, academic papers, investopedia for credibility)
- [ ] Images: alt text includes keyword variant
- [ ] Meta description: 150–160 characters, includes primary keyword
- [ ] URL slug: clean, keyword-based (e.g., /learn/yield-curve-explained-investing)
- [ ] Schema markup: Article schema for blog posts

### Site Architecture for SEO
```
fin-eye.com/
├── /app (the product — no index, auth-gated)
├── /learn/ (blog + educational content — fully indexed)
│   ├── /learn/macro/ (macro cluster pillar)
│   ├── /learn/backtesting/ (backtesting cluster pillar)
│   ├── /learn/sentiment/ (sentiment cluster pillar)
│   ├── /learn/technical/ (technical cluster pillar)
│   └── /learn/glossary (searchable glossary — huge for long-tail keywords)
├── /about (company story, team — builds trust)
├── /pricing (clear, linked to from all blog CTAs)
└── /blog (news, company updates, research reports)
```

### Link Building Strategy
1. **HARO (Help a Reporter Out):** Sign up and respond to finance/investing/fintech queries. Get quoted in media articles, earn backlinks from high-DA domains.
2. **Resource page outreach:** Finance professors, financial literacy nonprofits, and personal finance sites maintain "tools" resource pages. Email to be added.
3. **Unlinked mentions:** Use Ahrefs alerts for "Fin-Eye" mentions. When journalists mention you without linking, email them to add the link.
4. **Broken link building:** Find broken links on high-DA finance sites and offer Fin-Eye content as a replacement.
5. **Data/research posts:** Original data posts get natural backlinks from journalists and bloggers who cite the research.

## PART 5: CONTENT PRODUCTION WORKFLOW

### Writing Process
1. **Keyword research** (30 min): Confirm search volume + competition
2. **Outline** (30 min): H2 structure, key points, data to include, CTAs
3. **First draft** (2–3 hours): Write for readers, not search engines
4. **SEO pass** (30 min): Keywords in H2s, internal links, meta description
5. **Review + publish** (30 min): Proofread, add images/charts, set featured image
6. **Distribution** (15 min): Tweet link, Reddit post, add to newsletter queue

**Target:** 2 posts/week = 104 posts/year = significant search presence by end of Year 1

### Content Tools
- **SEO research:** Ahrefs or Ubersuggest (Ubersuggest is cheaper for bootstrapped stage)
- **Writing:** Notion (drafts), Grammarly (editing)
- **Analytics:** Google Search Console (free) + Google Analytics 4 (free)
- **Email collection:** ConvertKit or Beehiiv (for blog subscribers)
- **Social scheduling:** Buffer or Hypefury (for automated Twitter posting)
